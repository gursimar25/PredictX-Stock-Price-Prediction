PROJECT OVERVIEW

Stock Price Prediction
using Machine Learning

PredictX is a college mini-project demonstrating how historical market data, Python and machine learning can be combined in a secure web application.

How it works

Yahoo Finance provides historical OHLC and volume data through yfinance. The application builds rolling closing-price features, trains Linear Regression on chronological training data, evaluates it on a held-out section and generates the next-step estimate.

Technology

PythonFlaskyfinancePandasScikit-learnSQLiteChart.jsHTML/CSS/JS

Security

Passwords are stored as salted hashes, authenticated routes are protected, forms use CSRF protection, and user prediction history is isolated by user ID.

Limitations

Historical-price models cannot account for every market event. Results are educational estimates, not investment advice.
